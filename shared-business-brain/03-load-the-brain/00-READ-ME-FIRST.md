# Loading the brain into Claude

The brain is eight markdown files in a folder. That folder is the real thing.
A Claude Project is just one convenient way to put it in front of Claude, and
it is not the only one.

If you are all on a multi-user plan, route A gives you one shared brain and
there is nothing further to arrange — skip to it.

Otherwise, pick the route that matches what each of you has. **You do not all
need the same route, and you do not all need the same plan.** Everyone
reading the same files is what makes the answers match.

## The three routes

| You have | Route | What to do |
| --- | --- | --- |
| Claude **Team** or Enterprise | Shared Project | One person builds it; everyone gets it automatically |
| Claude **Pro** or Max | Your own Project | Each person builds their own from the same folder |
| Claude **Free** | Attach to the chat | No Projects on Free — attach the files you need, per chat |

### Route A — Team or Enterprise: one genuinely shared brain

This is the best version of the whole system, and if you are on a multi-user
plan there is no compromise to make.

1. Create a Project named after the business and share it with everyone.
2. Paste `01-project-instructions.md` into its custom instructions.
3. Upload the eight files from the shared folder.
4. Add the five skills.

One brain, held once. Everyone is reading the same files by default, with
nothing to remember and nothing to re-upload. When a file changes, one person
replaces it and the whole team has the new version immediately — no
announcement, no copies drifting apart.

Keep the folder anyway. Not because this route is lacking, but because the
folder is what you export, share with a contractor, and carry to another plan
later. See `04-moving-between-plans.md`.

### Route B — Pro or Max: your own Project, same files

Projects exist on Pro, but they cannot be shared between accounts. That is
fine. Each person does this once:

1. Create a Project named after the business.
2. Paste `01-project-instructions.md` into its custom instructions.
3. Upload the same eight files from the shared folder.
4. Add the five skills.

The result is identical for the person using it. The cost is that each of you
re-uploads after the files change, so agree who announces a change — the file
owner named in `channels.md`.

### Route C — Free: attach the files to the chat

Free has no Projects and no custom instructions, so the brain travels with
the message instead.

1. Keep the eight files somewhere reachable on your phone or laptop.
2. At the start of a chat, attach **the files that matter for what you are
   doing** — not all eight. Writing a post: `voice.md` and `offerings.md`.
   Answering a customer: `customer-faq.md` and `offerings.md`. Pricing
   question: `offer-rules.md` and `decisions.md`.
3. Paste `01b-instructions-for-a-single-chat.md` above your question.

Attaching two or three files rather than eight matters on Free, where the
daily limit is small. It also gives better answers — Claude reads a short,
relevant set more carefully than a long, mostly irrelevant one.

## Keeping one combined file

If someone is mostly on a phone, or mostly on Free, one combined file is
easier to attach than eight.

Ask Claude, in a chat with all eight files attached: *"Join these into one
file called `whole-brain.md`, keeping every heading and changing no wording.
Put a contents list at the top."*

Regenerate it whenever the files change — the monthly review is the natural
moment. Treat it as a copy, never as the master. Edits go to the eight files.

## What holds it together, whatever your plans

- **A folder** everyone can open. Drive, Dropbox, anywhere.
- **One person who keeps the master copy current**, named in `channels.md`.
  This is a maintenance job, not a gate — anyone can share these files with
  anyone, and `03-sharing-the-brain.md` suggests who gets which.
- **One announcement** when a file changes, so the other routes re-load it.

## The thing plans cannot fix

Claude's own memory is tied to each login on every plan, so it is never
shared, and it keeps diverging between you whatever you are paying. The eight
files are the only common ground. That is what `decisions.md` is for.

## Steps in order

1. Put the eight finished files in a shared folder.
2. Name one owner for them.
3. Each person picks a route above and sets it up once.
4. Read `02-keeping-the-tools-in-sync.md` together and fill in the `[FILL]`
   owners.
5. Add the five skills — routes A and B only. On Free, the checks live in the
   instructions you paste.

## The habit that makes it work

After any conversation that settles something, ask Claude to write the line
for `decisions.md`. Paste it into the file, in the shared folder. Two
minutes.

Without the habit this becomes a folder of ageing documents and everyone
drifts back to their own private version of the truth.
