# Loading the brain into Claude

The brain is eight markdown files in a folder. That folder is the real thing.
A Claude Project is just one convenient way to put it in front of Claude, and
it is not the only one.

Pick the route that matches what you have. **You do not all need the same
route, and you do not all need the same plan.** Everyone reading the same
files is what makes the answers match.

## Your route

| You have | What to do |
| --- | --- |
| Claude **Pro** or Max | Build a Project — the easy path |
| Claude **Free** | Attach the files you need at the start of a chat |

### On Pro or Max

1. Create a Project named after the business.
2. Paste `01-project-instructions.md` into its custom instructions.
3. Upload the eight files.
4. Add the five skills from `04-skills`.
5. Keep the same eight files in a folder you control. That folder is the
   master; the Project holds a copy.

### On Free

Free has no Projects and no custom instructions, so the brain travels with
the message.

1. Keep the eight files reachable on your phone or laptop.
2. Attach **the files that matter for what you are doing** — not all eight.
   Writing a post: `voice.md` and `offerings.md`. Answering a customer:
   `customer-faq.md` and `offerings.md`. Pricing: `offer-rules.md` and
   `decisions.md`.
3. Paste `01b-instructions-for-a-single-chat.md` above your question.

Two or three files beat eight here — the daily limit is small, and Claude
reads a short relevant set more carefully than a long one.

## One combined file, if you work on a phone

Ask Claude, with all eight attached: *"Join these into one file called
`whole-brain.md`, keeping every heading and changing no wording. Put a
contents list at the top."* Regenerate it when the files change. It is a
copy, never the master.

## Sharing

Send these files to anyone useful — a freelancer, a VA, whoever covers for
you, your accountant. See `03-sharing-the-brain.md` for which files suit
which audience.

## The habit that makes it work

After any conversation that settles something, ask Claude to write the line
for `decisions.md`. Paste it in. Two minutes.

Without the habit this becomes a folder of ageing documents and Claude keeps
forgetting exactly as it does today.
