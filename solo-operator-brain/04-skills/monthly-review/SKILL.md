# Monthly review

Work through this in order. Produce a short action list, not prose.

## 1. Gaps

List every [FILL] and [UNKNOWN] still open across the eight files. Rank them
by how often the missing information blocked an answer this month. Propose
closing the top three.

## 2. Staleness

- When was each file last reviewed? Name any older than 90 days.
- Does offerings.md still match wherever prices really live?
- Is anything in relationships.md out of date?

## 3. Contradictions

Name any place where two files disagree, or where a decision is contradicted
by current practice. Do not resolve them. Report them.

## 4. Decisions not logged

Ask what was decided this month. Anything named without an entry gets one
drafted now. Ask separately whether anything marked [UNRESOLVED] has since
settled.

## 5. Drift

Do customer-faq.md and offerings.md still match what any automation tells
customers? A mismatch means customers are getting a different answer from the
bot than from a person. Flag it as priority.

## Output

A numbered action list with an owner for each. Nothing else.
