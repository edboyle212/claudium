# Keeping it current

Working alone, there is nobody to notice when these files go stale. So the
maintenance has to be small enough that you actually do it.

## Direction rules

1. **Wherever prices really live is upstream.** Change them there first, then
   copy into offerings.md. Never the reverse.
2. **One folder holds the master files.** The Claude Project holds a copy.
3. **Claude drafts, you paste.** It never edits the master files.

## The ritual

| When | What | Minutes |
|---|---|---|
| A decision gets made | Paste the drafted entry into decisions.md | 2 |
| A price or offering changes | Update offerings.md, re-upload it | 5 |
| The same question arrives three times | Add it to customer-faq.md | 5 |
| First Monday of the month | Run the monthly review skill | 15 |

## Re-loading after a change

Nothing updates itself from your folder. If you use a Project, re-upload the
changed file to replace the old one. If you attach files per chat, you pick
up the new copy next time. Either way, do it straight away after any change
to offer-rules.md or offerings.md - those two do real damage when stale.

## Two things worth knowing

**Claude's memory and these files are different things.** Memory picks up
what you mention in passing, unevenly, and you cannot see all of it. The
files are deliberate and you can read them. When the two disagree, the files
are what you can check, so the files win.

**This is your handover document.** The first person you hire, the
bookkeeper, the person covering while you are ill - they do not need your
memory, they need how-i-work.md and customer-faq.md. That is worth more than
the time it saves you in chats.
