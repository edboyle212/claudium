# Moving between plans, and taking the brain with you

Your brain is not tied to a Claude plan, an account, or any one person. It
is eight text files in a folder the business owns.

## What travels, and what does not

| Travels with you | Stays behind |
| --- | --- |
| The eight files — they are plain markdown | Claude's memory of your private chats |
| The project instructions | The chat history inside a Project |
| The five skills | Anything you only ever said out loud to Claude |

The first column is the brain. The second column is why the brain exists.

Nothing you built here is locked to a plan, an account, or to Claude. The
files are text. They open in any editor, sync in any folder, and work with
any AI tool that can read an attachment.

## Before any change, export

Whatever you are moving between, do this first:

1. Download the eight files from wherever they currently live.
2. Check them against the folder copy. If the folder is behind, update it.
3. Only then change the plan.

The folder is the master copy for exactly this reason. A Project is a
convenient place to put the files; the folder is where they survive.

## Moving up

**Free to Pro.** Build a Project, paste the instructions, upload the eight
files, add the five skills. You stop attaching files to every chat.

**Pro to Team.** One person creates the shared Project, pastes the
instructions, uploads the files, adds the skills, and shares it. Everyone
else can delete their personal copy — from that point there is one brain,
and an update reaches everyone at once.

**Team to Enterprise.** The files move unchanged.

## Moving down, or out

**Team to Pro.** Export the files from the shared Project first. When the
team plan ends, so does access to anything stored only in it. With the folder
in hand, each person rebuilds a personal Project in about five minutes.

**Someone leaves.** The brain stays with the business, because it lives in
the business's folder. Their private Claude memory of your business leaves
with them, and you cannot retrieve it. That asymmetry is worth knowing before
somebody hands in notice, not after.

**Leaving Claude entirely.** The files go with you. The project instructions
and the skills are written as plain prose and will need adapting to whatever
you move to, but the content — what you sell, how you sound, what you decided
— transfers as it is.

## What to redo after any move

- Paste the project instructions again (they do not follow the files)
- Add the five skills again
- Re-upload the eight files
- Expect Claude to know nothing about you personally at first. It reads the
  files rather than remembering you, which is the point.

## The check worth doing once a year

Open the folder. If the newest file is a year old, the brain is not being
maintained, and no plan will fix that.

## Mixed plans are fine, and temporary

Nothing breaks if one of you is on Team, one on Pro and one on Free. Everyone
reads the same files, so everyone gives the same answers.

But it is worth being honest that it is more work than the alternative.
On Team there is one brain and one upload. On mixed plans there are several
copies of the same files, and somebody has to say when they change. If the
mixed arrangement is permanent rather than a step on the way, expect the
announcement step to be the part that slips.
