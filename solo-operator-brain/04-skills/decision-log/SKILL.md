# Log a decision

## When a decision has been made

Write the entry in exactly this format, in a code block ready to paste:

```
### YYYY-MM-DD - [decision in one line]
- Why: [the reason, not a restatement]
- Alternative rejected: [what was not chosen]
- Revisit when: [a trigger, or "not planned"]
```

## What counts as a decision

A change to what the business will do. Not a fact, not a finding, not an
option considered.

## When asked whether something was already decided

1. Search decisions.md before answering.
2. If there is an entry, quote it with its date.
3. If it is more than six months old and the situation has changed, say so.
4. If two entries conflict, stop and report the conflict. Do not pick one.
5. If an entry is marked [UNRESOLVED], say that plainly rather than treating
   it as settled.

## Reversals

Never edit or delete an old entry. Write a new one stating the reversal and
referring back. The record of changing your mind is the useful part.
