# Decision log

Started in the interviews, then grown one line at a time, forever. This is
the file the whole system depends on.

## Format

```
### YYYY-MM-DD - [decision in one line]
- Why: [the reason, not a restatement]
- Alternative rejected: [what we did not do]
- Revisit when: [a trigger, or "not planned"]
```

## Rules

- Log a decision when it changes what we will do, not when it merely informs
  us. "We looked at X" is not a decision. "We are not doing X until Y
  improves" is.
- Never delete an entry. If a decision is reversed, write a new one saying so
  and referring back. The reversal is the useful record.
- If two entries conflict, that is a finding, not a tidy-up job.
