# Check an offer against the rules

## The test

1. **Who is the audience?** If the offer reaches existing customers at a
   reduced price and offer-rules.md says otherwise, say so first, before
   helping build it.
2. **Does it fit what is used instead of cutting price?** If not, it is a new
   decision and needs a logged reason.
3. **Does it clear the hard limits?** Check the floor price, and who is
   allowed to agree a discount.
4. **What triggers it?** If the rules name a number to watch and the proposal
   is driven by a date instead, name the mismatch.

## If the offer breaks a rule

Do not refuse to help. State the conflict plainly, give the strongest case
for breaking the rule and the strongest case against, and say what evidence
would settle it. If offer-rules.md lists that rule as untested, say so - an
offer that would test it is an argument in its favour, and the result should
be logged.

## Always finish with

The measurement. What number tells us in 30 days whether this worked, and
where do we read it?
